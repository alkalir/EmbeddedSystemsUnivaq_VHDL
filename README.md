# Homelab FPGA

This Homelab is part of the **Embedded Systems** course at the **University of L'Aquila**.

## What is VHDL?

**VHDL** (VHSIC Hardware Description Language) is a language used to describe the structure and behavior of digital hardware. Unlike a software programming language, where instructions are executed one after another, a VHDL description defines *circuits*: components that exist and operate concurrently. The same description can be simulated, to verify that the design behaves as expected, and synthesized, to be implemented on hardware such as an **FPGA**.

## What does this repository offer?

This repository is a hands-on path to learning VHDL and FPGA design. It combines:

- **Theory**: the course slides on VHDL, to build the concepts you need.
- **Practice**: a set of guided tasks, split into five sections, to apply those concepts on real designs.
- **Ready-to-use material**: the VHDL source files and testbenches needed to carry out the lab.

It is designed for the students of the Embedded Systems course, but it works well for anyone who wants to approach VHDL step by step.

The Homelab must be completed by working through **all the tasks** included in the **five sections** provided.

The files required to carry out the lab (e.g., VHDL source files, testbenches) are located in the `hw/` folder.
